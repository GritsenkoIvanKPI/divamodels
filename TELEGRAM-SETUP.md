# Заявки → Telegram

Заявки с сайта уходят в группу **DIVA MODELS** через бота **@bunxymodels_bot**.

Отправляют заявки два места, оба уже подключены:

| Форма | Файл | Метка в сообщении |
|---|---|---|
| Попап на сайте | `apply-form.html` | `Попап на сайте` |
| Рекламный лендинг | `apply.html` | `Рекламный лендинг` |

---

## Где лежит токен

**Токена нет ни в одном файле репозитория — и не должно быть.** Кто угодно,
получив токен, может читать ваши заявки и управлять ботом.

Есть два места, откуда код его берёт:

1. **Переменные окружения** — `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
   Самый безопасный вариант, работает и на Vercel, и на Node-хостинге.
2. **Файл `telegram-config.php`** — только для обычного PHP-хостинга, где
   переменные окружения задать нельзя. Файл в `.gitignore`, в репозиторий
   не попадает. Образец — `telegram-config.example.php`.

---

## Что осталось сделать

Сайт будет лежать на статике (GitHub Pages + домен). Там **не выполняется ни
PHP, ни Node** — значит, `send.php` и `api/lead.js` там просто не запустятся.
Поэтому нужен маленький посредник, который примет заявку и сходит в Telegram.

### Вариант А — Cloudflare Worker (рекомендуется)

Бесплатно, 5 минут, и работает с **любого** хостинга — хоть GitHub Pages,
хоть обычный хостинг. Токен лежит в секретах Cloudflare, в браузер не
попадает.

1. `dash.cloudflare.com` → **Workers & Pages** → Create → Worker → Deploy
2. **Edit code** → вставить весь `cloudflare-worker.js` → Deploy
3. **Settings → Variables and Secrets** → добавить:

   | Имя | Тип | Значение |
   |---|---|---|
   | `TELEGRAM_BOT_TOKEN` | Secret | токен от BotFather |
   | `TELEGRAM_CHAT_ID` | Secret | `-1002276800723` |
   | `ALLOWED_ORIGINS` | Text | `https://ваш-домен.com,https://www.ваш-домен.com` |

4. Скопировать адрес воркера и вписать его **в двух файлах** —
   `apply.html` и `apply-form.html`:

   ```js
   var LEAD_ENDPOINT = 'https://ваш-воркер.workers.dev';
   ```

После этого архив с сайтом можно заливать куда угодно — форма будет работать.

### Вариант Б — если хостинг всё-таки с PHP

1. `telegram-config.example.php` → скопировать в `telegram-config.php`,
   вписать токен и id группы. Этот файл **не коммитить**.
2. Положить `send.php` и `telegram-config.php` в корень сайта.
3. В `apply.html` и `apply-form.html`:
   ```js
   var LEAD_ENDPOINT = 'send.php';
   ```

### Что заливать на статический хостинг

Нужны: все `.html`, папки `assets/` и `images/`.
Не нужны и не работают там: `send.php`, `api/`, `telegram-config*.php`,
`serve.mjs`, `screenshot.mjs`, `node_modules/`, `*.md`.

## Защита

- **Токен не попадает в браузер.** Страница обращается только к своему
  адресу, а сервер уже сам ходит в Telegram.
- **Ловушка для ботов.** В форме есть скрытое поле: человек его не видит,
  спам-бот заполняет. Такие заявки отбрасываются молча.
- **Ограничение частоты.** Не больше 5 заявок с одного IP за 10 минут,
  дальше — 429. Работает без базы, поэтому это заслон от потока, а не
  строгая гарантия.
- **Проверка данных.** Пустые поля отклоняются, длинные обрезаются, HTML
  экранируется — в сообщение нельзя подставить разметку.

## Проверка

Отправьте тестовую заявку:

| Что видно | Что это значит |
|---|---|
| Экран «Заявка отправлена!» | всё работает, сообщение уже в группе |
| Красная строка «Не удалось отправить» | сервер не принял — см. ниже |

Успех **никогда** не показывается, если сообщение не ушло, — иначе лиды
терялись бы незаметно.

Частые причины ошибки:

- `not_configured` — не заданы переменные окружения (или забыли Redeploy)
- `chat not found` — бота удалили из группы, или id без минуса
- `403 Forbidden` — бота заблокировали или исключили из группы
- 404 на адрес — `LEAD_ENDPOINT` не совпадает с вариантом хостинга
- `too_many_requests` — сработало ограничение частоты, подождите 10 минут

Ошибки пишутся в лог: на Vercel — вкладка **Logs**, на PHP — `error_log`.

---

## Если токен утёк

В @BotFather: `/revoke` → выбрать бота → он выдаст новый токен. Старый
перестаёт работать сразу. После этого обновить переменную окружения
(или `telegram-config.php`) и сделать Redeploy.
