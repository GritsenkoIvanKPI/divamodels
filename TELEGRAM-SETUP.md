# Подключение заявок к Telegram

Заявки с сайта уходят в группу Telegram. Формы уже настроены и отправляют
данные — осталось создать бота и включить приём на стороне сервера.

Отправляют заявки два места, оба уже готовы:

| Форма | Файл | Метка в сообщении |
|---|---|---|
| Попап на сайте | `apply-form.html` | `Попап на сайте` |
| Рекламный лендинг | `apply.html` | `Рекламный лендинг` |

---

## Шаг 1. Создать бота

1. В Telegram открыть [@BotFather](https://t.me/BotFather) → `/newbot`
2. Придумать имя и username
3. BotFather выдаст **токен** вида `1234567890:AAH...`

> **Токен — как пароль.** Его нельзя вставлять в HTML, в JS или отправлять в
> переписке. Он живёт только на сервере (см. шаг 3).

## Шаг 2. Узнать ID группы

1. Создать группу, добавить менеджеров
2. Добавить туда бота
3. Написать в группе: `/start@имя_вашего_бота`
4. Открыть в браузере: `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
5. Найти `"chat":{"id":-1001234567890` — это и есть ID (число **отрицательное**)

Проще: добавить в группу [@RawDataBot](https://t.me/RawDataBot), он покажет ID,
потом удалить его из группы.

## Шаг 3. Включить приём — выбрать один вариант

### Вариант А. Обычный PHP-хостинг (cPanel, Hostinger, Beget, Timeweb…)

1. Открыть `send.php`, вписать токен и ID группы в две строки вверху
2. Положить `send.php` в корень сайта, рядом с `index.html`
3. В `apply.html` и `apply-form.html` найти `LEAD_ENDPOINT` и поставить:
   ```js
   var LEAD_ENDPOINT = 'send.php';
   ```

### Вариант Б. Node / Vercel / Netlify

1. Файл `api/lead.js` уже на месте, менять его не нужно
2. В панели хостинга добавить две переменные окружения:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather
   - `TELEGRAM_CHAT_ID` — ID группы
3. `LEAD_ENDPOINT` уже стоит `'/api/lead'` — ничего не трогать
4. Сделать Redeploy


Ссылка на страницу приходит целиком, вместе с UTM-метками — по ней видно,
с какой рекламы пришёл лид.

## Проверка

Отправьте тестовую заявку. Возможные исходы:

| Что видно | Что это значит |
|---|---|
| Экран «Заявка отправлена!» | всё работает, сообщение в группе |
| Красная строка «Не удалось отправить» | сервер не принял — см. ниже |

Заявка **никогда** не показывает успех, если сообщение не ушло, — иначе лиды
терялись бы незаметно.

Частые причины ошибки:

- `chat not found` — бот не добавлен в группу, или ID без минуса
- `not_configured` — не заполнены токен и ID
- `403 Forbidden` — бота удалили из группы или заблокировали
- 404 на адрес — `LEAD_ENDPOINT` не совпадает с вариантом хостинга (шаг 3)

Ошибки пишутся в лог сервера: на PHP — в error_log хостинга, на Vercel —
во вкладке Logs.

## Спам

В форме есть скрытое поле-ловушка. Человек его не видит, а спам-боты
заполняют автоматически — такие заявки отбрасываются и в группу не попадают.
